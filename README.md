# Nasima Islam Bithi — Research Portfolio (v2)

A refreshed, responsive academic portfolio based on the provided CV. Built with plain **HTML, CSS, and JavaScript**, no build tools required.

## Features
- Separate clickable tabs: Home, About, Experience, Publications, Projects, Education, Awards, Contact
- Publication list with **8 entries**, category filters, keyword search, and sorting
- Expandable research/project details
- Education and affiliation logos (web image sources with built-in abbreviation fallback)
- Light/dark mode switch, responsive mobile menu, linkable hash routes
- Dedicated honors and awards page
- Accessibility basics (labels, `aria-pressed`, keyboard-focus styles)

## Publish on GitHub Pages
1. Open https://github.com/Nasima-Islam-Bithi/bithi-portfolio
2. Upload all files to the **repository root**. Replace older `index.html`, `style.css`, `script.js` and `README.md`.
3. Go to **Settings → Pages → Build and deployment**.
4. Select **Deploy from a branch**, branch `main`, folder `/(root)` and save.
5. Site: https://nasima-islam-bithi.github.io/bithi-portfolio/

Logo images are hosted on third-party sites and need an internet connection. If an image cannot load, an institution abbreviation is shown instead.

## Attribution and accuracy
- Content transcribed/summarized from the user-supplied CV.
- NoiseNet is **accepted for publication** as stated in the CV, not represented as published.
- Publication buttons run a title search on Google Scholar instead of pretending to have verified DOI URLs.
- Official institution/affiliation logos or publicly displayed emblems are used for identification; trademarks belong to their respective owners.
- No GitHub repositories for individual research projects are asserted unless verified.

## Update your links
Edit `index.html` in the Contact section to add verified Google Scholar, ORCID, and LinkedIn URLs.
Edit the `publications` array in `script.js` for new papers.
